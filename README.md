# SAP S/4HANA: ERP Business Process Case Studies

**Academic portfolio | Webster University in Tashkent**  
**Author:** Charoskhon Farkhadova  
**Focus:** ERP fundamentals · Business processes · Production planning · Warehouse management · SAP GUI

## Project overview

This portfolio documents selected **educational exercises** completed in an SAP learning environment. The work focuses on understanding how enterprise software connects inventory, production, fulfillment, and accounting concepts. It also covers SAP GUI navigation and the structure of the SAP Customizing Implementation Guide (IMG).

This is **an academic case-study portfolio, not an independently deployable SAP implementation**. It does not contain company data, an SAP system export, a custom-developed SAP extension, or production configuration scripts.

## Case studies

### [01. SAP GUI and configuration navigation](docs/configuration-foundations.md)

An introduction to distinguishing everyday SAP transactions from consultant-oriented configuration menus, interpreting transaction navigation paths, and working with screen controls and system messages.

### [02. Warehouse and inventory transfer](docs/warehouse-management.md)

A documented stock transfer of **10 units** between two simulated locations. The educational exercise follows the lifecycle from transfer order through goods issue, in-transit stock, goods receipt, and warehouse putaway.

### [03. Production planning and execution](docs/production-planning.md)

An educational manufacturing scenario that covers product master-data preparation, BOM/routing assignments, planned independent requirements, a **100-unit production order**, component goods issue, finished-goods receipt, and settlement.
